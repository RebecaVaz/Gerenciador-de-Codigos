# Automa-o-de-Gerenciamento-de-C-digos-
Aplicação desenvolvida em Python + Tkinter para automatizar a análise e o gerenciamento de catálogos PDF, com detecção de duplicidades, controle de numeração, identificação de itens disponíveis, comparação de versões e backups sincronizados, reduzindo inconsistências e otimizando processos operacionais.

### Instalação

**1. Pré-requisitos**

- Python 3.8 ou superior.
- Bibliotecas externas listadas em `requirements.txt`.

**2. Instalar dependências**

No terminal, execute:

```bash
pip install -r requirements.txt
```

**3. Executar o programa**

```bash
python Sistema.py
```

**Observação:** Os módulos `tkinter`, `sqlite3`, `re`, `os`, `shutil` e `collections` já fazem parte da biblioteca padrão do Python, não sendo necessária sua instalação individual.
